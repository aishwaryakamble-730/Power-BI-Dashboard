# 📊 Power BI Analytics Project

This repository contains a collection of Power BI reports, dashboards, and data models created as part of my Power BI analytics assignment. The project demonstrates skills across DAX calculations, data modeling, Power Query transformations, visualization techniques, and interactive dashboard design.

---

## 🚀 Project Highlights

### **Power BI Concepts & Platforms**
Includes an overview and explanation of Power BI, its ecosystem, and platforms such as Desktop, Service, Mobile App, Report Server, and Data Gateway.

---

## 📈 Visualizations & Reports Created

### **Year-over-Year Sales Comparison**
Using the Superstore dataset:
- Designed a **Line and Clustered Column Chart**
- Built DAX measures to calculate:
  - Current Year Sales
  - Last Year Sales
  - YoY Growth %
- Compared yearly performance through visual insights

---

### **Box Office Data Model (3-Year Master Table)**
Using Box Office Mojo data:
- Imported 3 years of movie box office data into Power Query  
- Cleaned and combined the files into a **Master Table**  
- Loaded only the final consolidated table to Power BI  
- Built a structured and optimized data model

---

### **Waterfall Analysis**
Created a **Waterfall Chart** using the Superstore dataset to show:
- Category-wise performance  
- Yearly changes and contributions to total sales  

---

### **Location-Based Sales Hierarchy**
Developed a custom hierarchy named **Location**:
- Country → State → Region → City → Postal Code  
Used to visualize detailed **location-wise sales analysis**.

---

### **Bookmarks for Time-Based Navigation**
Using the Finance dataset:
- Built a Clustered Column Chart
- Applied **Bookmarks** for switching views between:
  - Year  
  - Quarter  
  - Month  
- Created an intuitive time-based navigation experience

---

### **Drill-Through Analysis**
Built an interactive drill-through experience:
- Donut chart showing region-wise profit  
- Detailed page for the **West Region** for deeper insights  

---

### **Conditional Formatting Dashboard**
Developed a table visual with advanced formatting rules:
- Sales → background color gradient (red to green)  
- Profit → arrow icons (negative/positive)  
- Quantity → data bars  
- Discount → color-coded text (red to green)  

---

## 💼 Finance Dashboard
